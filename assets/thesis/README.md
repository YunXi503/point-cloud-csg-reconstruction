# 論文原圖與候選表

圖庫入口：[依方法與四個案例閱讀](../../docs/figures/README.md)。

fig-*.png 為指定 Word 內嵌媒體的原位元複本；含多個子圖時，以 a、b、c 區分。table-*-candidates.png 為同一公開 PDF 的候選表區域，以 3 倍比例渲染，保留原表題、數值及浮水印。

本目錄的圖件保留論文著作權。[來源、Word 版面裁切設定、PDF 頁碼與 SHA-256](../../provenance/thesis-figures.json)；完整正式版面見 [論文 PDF](../../paper/thesis-public-snapshot-20261105.pdf)。

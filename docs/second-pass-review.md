# 第二輪審查與改善

第一輪完成來源保存及重現後，改從新訪客、維護者與研究可追溯性三個角度檢查。這是同一執行者採不同準則的第二輪審查，不冒充外部學術盲審。

| 發現 | 改善 | 驗證依據 |
|---|---|---|
| 首頁以封裝與缺件數量為主，研究價值不易理解 | 加入真實 CSV 預覽、問題與輸出說明、兩種入口 | 圖件來源雜湊及視覺檢查；每範例保留全部 10000 點 |
| 頂層套件版本不等於完整鎖定環境 | 新建 venv、記錄 13 個套件，提供 bootstrap 及 lock | 搬移副本重新安裝及執行通過 |
| NumPy 2.4.0 已撤回 | 保留對照，只換 2.4.1 | 其他套件不變；各環境 24 項相符 |
| C# Main 固定桌面路徑 | 來源連結及 Execute 轉接器傳入路徑 | 未改研究檔，搬移後 4 初始 CSV＋24 核心輸出相符 |
| L型板目錄名不能證明版本 | 綁定相符的既有幾何邏輯版，保留基本分割器失敗紀錄 | 初始及後續 6 項相符；未作內部差異消融歸因 |
| 盲孔輸出受 runtime 影響 | 同源改查 .NET 8，記錄實測環境，不改輸出程式 | 初始及後續 6 項相符；不推定歷史 runtime |
| 雜湊工具未偵測新檔 | 加入未知檔案檢查 | 負向測試會非零退出 |
| 缺少安全的重封裝工具 | 提供先保護研究來源的 seal-release | 修改研究來源時，拒絕替它重新背書 |
| 新腳本及 CI 也可能被換行轉換 | 全檔預設停用隱式轉換，新文字指定 LF，研究快照保留原位元 | Git 屬性及實際 checkout 完整性查核 |
| 論文實存檔與早期索引雜湊不同 | 查出文字差異，明確標示現存 Word 的公開快照 | Word 實際開啟，75 頁；oMath 97→97；原檔及副本不變 |
| 原稿 NIST 名稱錯誤 | 在論文版本頁列勘誤與官方依據，不靜默改寫 | PDF 及官方頁比對 |
| 重現容易被誤寫成準確率或泛化 | 明列 STL 生成資料、平面／圓柱及 CSG 推論表示 | README、實作對照與查驗紀錄交叉檢查 |

## 保留邊界

3 個歷史 csproj 缺件保留供追溯，現行來源連結入口不依賴其缺件。STL／Blender 重取樣、真實掃描及 CAD 幾何核心輸出，不屬該版已驗證能力。

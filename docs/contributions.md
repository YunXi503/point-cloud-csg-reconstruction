## 方法目標與取捨

以下將論文目標與程式可觀察的設計放在一起，供閱讀者評估實作。這些取捨分析與當年的個人選型動機分開記錄。

| 設計 | 帶來的能力 | 代價與邊界 |
|---|---|---|
| 同時使用點位置與曲面法向量 | 讓群集、面型及方向條件都有可查資料 | 依賴輸入法向量與取樣品質；目前資料來自 STL 取樣 |
| 保留面、拓樸、候選等中間層 | 可以由候選 ID 回查來源面與判斷關係 | 增加中間資料及版本一致性維護工作 |
| 使用明確規則與布林角色建立 CSG 推論 | 可以檢查 Union／Difference 的來源及組合順序 | 現行語義角色含案例專屬條件，擴充新模型需要重新驗證 |
| 曲面殘差與候選尺寸誤差分開驗收 | 分別檢查表面貼合及相對參考幾何的參數差異 | 需要兩套指標及各自適用的容許值 |
| 保存研究來源並以轉接器提供新入口 | 讓公開工程入口可與歷史輸出核對 | 保留舊程式及環境限制，需清楚標示來源與 runtime |

C# 與 Python 的既有工作分工可從程式確認；選用語言時的個人考量尚無完整歷史紀錄，因此本頁說明目前分工及可觀察取捨。待補資訊見[資料缺口](missing-information.md)。

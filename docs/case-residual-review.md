## 內容查核與處理

| 檢查項目 | 最終處理與理由 |
|---|---|
| 四案例被解讀為四級難度？ | 按定稿4.7節分開：前三例易／中／難；盲孔例另查端部條件。沒有新建難度分數 |
| 模型A被當成通用上限證明？ | 說明其為已測的較複雜指定構型，不將定稿「適用上限」外推為完整搜尋結果 |
| 輸出計數被當辨識正確率？ | 面／邊／候選數只作描述，原程式含案例條件；五層品質與輸出SHA各有不同證據用途 |
| 混淆面級最大值與逐點分布？ | 由43份面記錄分組，31平面／12圓柱面；只彙整FitResidualMax，不計假RMSE或將FitResidualMedian合併為全體中位數 |
| 網格化寫成唯一原因？ | 保留定稿原文，導讀分開觀察、可能機制與待驗證因果；不宣稱單因、誤差地板或與複雜度無關 |
| 取樣快照當逐次來源收據？ | 說明面積CDF、面片內取樣及面法向量邏輯，明列未重跑及未補造網格／modifier生成鏈 |
| 小殘差等於半徑正確？ | 分開擬合殘差、候選參數誤差及解析短弧fixture；後者不來自STL，不歸入網格化原因 |

## 來源與驗收

[機器可讀證據](../provenance/case-residual-evidence.json)列出定稿章節原文、四例CSV、保存方法參數、函式位置及24份來源SHA。CSV讀回保留九位小數，統計使用原文字精度；數字來源可逐面回查。

判準是導讀數字與保存欄位一致、推論強度符合證據、原檔與程式不變。[文件稽核](../validation/2026-11-06/case-residual-audit.json)記錄原241來源、定稿Word／PDF、全部程式／測試／輸入／圖件與舊證據保留，並查核文件連結及來源行號。Word仍oMath97，沒有產出新的正式論文或宣稱新增格式QA。

該版沒有新增單元測試或研究模型；既有65項單元測試、12項CLI重放及兩條四案例路徑仍由當次CI執行，成敗以Actions日誌為準。

## 證據的適用邊界

四例各10000點，皆為STL生成的受控資料。兩條重現入口使用相同四例；輸出雜湊一致不增加研究模型數，也不等於未知零件辨識正確率。

封底判準使用有限取樣的徑向極值代理，沒有檢查完整圓盤覆蓋；0端封底、2端封底與不完整覆蓋的專屬分支驗證仍缺。CSG輸出為符號推論表示，未執行CAD實體布林求值。

約0.03 mm圓柱面殘差與網格近似機制相容，但沒有網格解析度受控對照或誤差來源分解，不能歸為已證實的單一原因或不可降低誤差地板。解析短弧fixture不來自STL；步長達標與小殘差均不保證半徑準確。

時間與峰值工作集只支持指定機器、來源及工作量的觀察；完整方法跨N、程序樹記憶體、跨硬體比較、真實掃描及未知零件泛化仍未驗證。[完整資料缺口](missing-information.md)

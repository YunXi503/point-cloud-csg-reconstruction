四個模型的用途與約0.03 mm殘差的解讀，見[案例目的對照](case-validation-map.md)與[殘差證據邊界](residuals-and-stl.md)，避免將案例描述或可能歸因說成泛化／因果結論。

[首頁](../README.md) · [L型板逐層導讀](case-walkthrough.md) · [來源與數值](../provenance/interview-evidence.json) · [仍缺資料](missing-information.md)

研究內容可先讀[問題與貢獻總覽](research-overview.md)，再沿[孔洞端部判別](hole-end-conditions.md)與[拓樸規則例解](topology-rules.md)查實際面組、來源與判斷限制。這三頁整理既有論文／程式，沒有新增研究實驗。

目前證據涵蓋指定案例的幾何計算、圖關係推論、來源追溯與重現；未知模型泛化、完整方法跨規模效能及完整數值邊界仍待驗證。

## 成本分析：從程式讀出什麼

以下是靜態分析；[實測報告](measurements.md)與[數值診斷](geometry-diagnostics.md)分別列出，不把靜態上界當實測曲線。N 為點數，M 為距離範圍內的候選點對數，K 為初始分量數，F 為面數，R 為未歸屬點數，m 為單次擬合點數，C 為候選單元數。已有四例兩階段時間／峰值工作集與一項函式的N曲線；尚無全方法跨N或相同工作量的比較基準，因此沒有加速比。

| 實作位置 | 可推導的成本或儲存量 | 分析限制 |
|---|---|---|
| [L型板 C# 初始分類](../research/%E7%A2%A9%E5%A3%AB%E8%AB%96%E6%96%87/%E7%A8%8B%E5%BC%8F%E7%A2%BC%E5%82%99%E4%BB%BD/%E7%89%B9%E5%BE%B5%E8%BE%A8%E8%AD%98%E6%A0%B8%E5%BF%83%E6%BC%94%E7%AE%97%E6%B3%95/L_Bracket%E5%B9%BE%E4%BD%95%E9%82%8F%E8%BC%AF/L-Bracket%20%E5%B9%BE%E4%BD%95%E9%82%8F%E8%BC%AF.cs#L431) | 每次從 stack 取點後掃描整個 points；此分群迴圈為 O(N²) 掃描量，已標記點仍會進入 foreach 再跳過 | 這是此來源的迴圈分析，不等於所有案例分類器都相同；已保存四例C#分類階段量測，但沒有這個內部迴圈單獨的時間或跨N量測 |
| Python region_growing | 先實體化 M 個點對，再作 M 次方向條件與稀疏圖建構；陣列／圖的儲存量為 O(N+M)；M 最多可達 N(N−1)/2 | KD-tree 不會消除回傳大量點對的成本。建樹、半徑搜尋與 connected_components 的實際成本另計，不能把整個方法稱為 O(N log N) |
| fit_plane／fit_cylinder | 使用 m×3 的 SVD／最小平方法資料；圓擬合最多 100 輪，每輪建立 O(m) 的殘差與 Jacobian | 輪數上限與步長門檻不等於所有輸入均收斂；已實測退化／短弧；發現100輪仍未達步長及小殘差卻有半徑誤差，見幾何診斷 |
| merge_surface_components | 以每個分量重新掃描標籤建立索引，這部分為 O(NK)；有效分量的比較有 O(K²) 個面組 | parent 字典有路徑壓縮，但未據此宣稱整體近線性。未歸屬點迴圈還會重算各面支撐範圍，其成本不能只寫 O(RF) |
| build_topology 與邊界統計 | 拓樸比較 F(F−1)/2 個面對；本例 F=12，即靜態推得 66 個面對，最後接受 24 條邊；每個面對內仍有點集搜尋 | 邊界統計另有有序面對查詢，部分 cKDTree 反覆建立。66 是迴圈面對數，並非時間量測或所有內部查詢總數 |
| graph_connected／build_candidates | 鄰接表、set、deque 查連通；建圖先掃描拓樸邊，鄰居另有排序。部分面 ID 查詢仍用 next 線性搜尋 | 不能只看到 BFS 就把整段候選推論寫成 O(V+E)，也不能把已知角色表當任意零件的通用搜尋 |
| canonical_csg_tree | 兩組候選排序 O(C log C)，組成清單 O(C) | 僅為符號表示及序列化成本，沒有包含實體幾何布林運算 |

## 測試與回歸證據

| 層級 | 已有證據 | 證據邊界 |
|---|---|---|
| 單元測試 | 65項：17工程防護、4解析幾何基準、2量測工具、34圓擬合外層／CLI、8重放檢查器 | 軟體fixture不增加研究案例；預期拒絕不等於求解成功 |
| CLI集成重放 | 六份解析fixture CSV×兩個原求解器，共12項；CI檢查狀態、退出碼、輸入SHA及參數未驗證旗標 | 原步長達標不保證半徑準確，外層不替參數背書 |
| 固定案例回歸 | 四份初始CSV與24項Python核心輸出；兩條入口查同四例 | 不保證新零件、旋轉、尺度、雜訊或任意點數有效 |
| 研究幾何品質 | 保存的曲面殘差及相對獨立STL／網格參考的候選參數誤差 | 不等於真實掃描準確率、效能優勢或一般CAD實體輸出 |
| 歷史敏感度 | 保存變體／輸出SHA與[標記勘誤](sensitivity-errata.md)，含一組未完成 | 不證明所有門檻最佳、C#內部消融或未知資料魯棒性 |

65項為v0.1.8起的單元測試合計；12項CLI重放另計。歷史v0.1.5、v0.1.6與v0.1.7分別為17、23及51項，舊報告保留當版數量。[查驗判準與報告](validation.md)

完整路徑的初始CSV另記位元SHA；資料內容比較允許表示不同但同一有限float64值的數字。六項核心輸出仍採嚴格SHA。應分別閱讀initial_bytes_match、initial_comparison與outputs；保存的四份初始CSV亦逐位元相同。

## 來源檢查與待補驗證

兩個入口依[固定依賴綁定](../provenance/inference-dependencies.json)預檢選定案例的Python主程式及顯式本地輔助程式。發現改動或遺失時停止並保存原因；第三方套件另由requirements.lock.txt鎖定。來源預檢不代替套件驗證或程式沙箱。

| 尚缺或技術債 | 現況 | 需要補充的證據 |
|---|---|---|
| 完整效能與規模 | 已有四例分類／推論時間、程序峰值工作集及region_growing的1000–10000點曲線 | 完整方法跨N、內部子階段、程序樹、含編譯延遲、跨硬體與相同工作量的比較基準 |
| 數值邊界 | 已有4項解析基準、20項曲面行為與12項收斂觀察；原限制保留 | 完整三維拒絕契約、尺度／平移／雜訊下的準確度界線及獨立參數參考 |
| 重複擬合及反覆建樹 | 原研究來源保留；靜態可見重複工作 | 熱點量測與一次一變數的最佳化對照；沒有據此宣稱加速 |
| 多案例角色與格式 | 各案例契約分別記錄，兩種CSG JSON格式並存 | 新模型的輸入／輸出及拒絕契約，既有案例不足以推出通用API |
| 來源檢查範圍 | 已綁定本版顯式本地匯入，外層另檢查來源清單結構 | 動態匯入、一般化依賴圖與依賴安全掃描尚無完整證據 |
| 歷史開發及失敗收據 | [M1–M3](missing-information.md)列明可回查資料 | 不能用現今分析代填當年的選型動機或失敗輸入SHA |

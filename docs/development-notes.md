# 來源與開發紀錄

研究程式、資料及參考輸出取自既有論文工作區及原 VS 工作區，依來源雜湊保存。目錄名稱或修改時間不單獨作為版本判準。

依作者於 2026-11-05 確認，研究實作、模型與資料、程式、實驗驗證、圖件及論文撰寫由黃云析完成，指導教授鄭宗明提供研究概念與題目方向。[分工與技術取捨](contributions.md) · [作者聲明](../provenance/contribution-statement.json)

2026-11-05 的工程整理由 Codex 協助新增命令列轉接、環境建立、測試、CI、圖件及文件。這些工程工具沒有被回溯宣稱為當年論文原始實作；執行結果、失敗嘗試與來源綁定另存紀錄。

本機查驗先保存來源，再建立不修改演算法的入口。L型板來源及盲孔 runtime 的不同結果保留為版本證據，沒有調整研究參數或捏造結果來消除差異。

# 研究程式與資料來源

本目錄保留研究工作區的相對目錄結構，避免在本輪整理中改寫研究方法。

| 目錄 | 用途 |
|---|---|
| tools/ | 四個範例的推論、驗證、圖件與相關方法工具，包含可辨識的本地匯入依賴 |
| 零件/ | 四個範例的模型、點雲、初始分割輸入及取樣程式快照 |
| 碩士論文/程式碼備份/ | C# 原始碼與專案備份 |
| 碩士論文/第四章驗證結果_260721/ | 階梯狀圓柱的獨立驗證資源 |
| 碩士論文/第四章驗證結果_260722/ | 階梯狀圓柱及 L型板的選定方法參考資料 |
| 碩士論文/第四章驗證結果_260724/ | 模型A的選定方法參考資料及獨立驗證資源 |
| 碩士論文/第四章驗證結果_260725/ | 盲孔六角座歷史參考資料及獨立驗證資源 |
| 碩士論文/審查報告/敏感度分析_260731/ | 既有敏感度分析摘要，不包含各參數變體的重複執行目錄 |

研究來源中的固定桌面路徑、Windows 字型位置與既有輸出位置仍保留。部分圖件程式可能寫入本目錄的相對位置，請在工作副本執行。新推論結果應另存 `runs/`。

獨立真值只供驗證；不能將其改作推論輸入。各程式的實際角色、輸入與版本以既有紀錄和 [cases.json](../examples/cases.json) 為準。
